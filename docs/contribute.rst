Contribute to Percona Toolkit
*****************************

We welcome community contributions to Percona Toolkit. Help improve the project by reporting bugs, suggesting documentation improvements, or contributing code.

Explore the following resources to find answers, learn best practices, and stay up to date with Percona Toolkit:

* `Percona Community Forum <https://forums.percona.com/c/polyglot-projects/percona-toolkit/13>`_ – Browse existing discussions, ask questions, and connect with the Percona community.
* `Percona Blog <https://www.percona.com/blog/category/mysql/>`_ – Read technical articles, tutorials, and best practices for Percona Toolkit and MySQL.

Report an issue
===============

Before creating a new issue, search the existing issues in `Percona Jira <https://perconadev.atlassian.net/jira/software/c/projects/PT/list>`_ to avoid duplicates. You can use `this guide <https://www.percona.com/blog/2019/06/12/report-bugs-improvements-new-feature-requests-for-percona-products/>`_ to structure the information.

When reporting an issue, include:

* A clear and descriptive title.
* The Percona Toolkit version.
* Operating system and database version.
* Steps to reproduce the issue.
* The expected and actual results.
* Error messages, logs, or other relevant details.

Documentation issues should be reported in the **PT** project in `Percona Jira <https://perconadev.atlassian.net/jira/software/c/projects/PT/list>`_ using the **Documentation** component.

Contribute to documentation
===========================

Documentation contributions of any size are welcome. You can help by:

* Correcting typos or grammatical errors.
* Improving explanations.
* Adding examples or clarifying existing procedures.
* Suggesting new content or topics.

Documentation updates can be submitted as GitHub pull requests.

Submit a pull request
===========================

Before submitting a pull request:

* Keep each pull request focused on a single issue or feature.
* Write clear and descriptive commit messages.
* Add or update tests where appropriate.
* Ensure existing tests pass.
* Follow the project's coding style and conventions.

Create a pull request
-------------------------

* Fork the `Percona Toolkit GitHub repository <https://github.com/percona/percona-toolkit>`_.
* Clone your fork to your local machine.
* Create a branch for your changes.
* Implement and test your changes.
* Push the branch to your GitHub fork.
* Open a pull request against the Percona Toolkit repository.

For detailed information about setting up the development environment, coding guidelines, testing, and submitting pull requests, see the `Percona Toolkit GitHub contribution guide <https://github.com/percona/percona-toolkit/blob/3.x/CONTRIBUTING.md>`_.
